# 手机版操作：3步出模型

## 第1步：注册Kaggle（2分钟）

1. 手机浏览器打开 **https://www.kaggle.com**
2. 用Google账号或邮箱注册登录
3. 点右上角头像 → **Settings** → **Phone Verification** → 验证手机号（必须，否则用不了GPU）

## 第2步：上传Notebook（30秒）

1. 回到Kaggle首页，点左上角 **≡** 菜单 → **Create** → **New Notebook**
2. 点上方 **File** → **Import Notebook** → 上传我给你的 `train_yolo_kaggle.ipynb`
3. 右侧面板设置：
   - **Accelerator** → `GPU T4 x2`
   - **Internet** → 打开（变蓝色）

## 第3步：运行（15分钟）

1. 点右上角 **Save Version**
2. 选 **Save & Run All (Commit)**
3. 弹框直接点 **Save**
4. 等15分钟（可以关掉浏览器，Kaggle在云端跑）
5. 跑完后会收到Kaggle邮件通知

## 第4步：下载模型

1. 回到Notebook，点右上角 **...** → **View Logs / Versions**
2. 选最新版本 → **Output** 标签
3. 找到 `qingyun_model.zip`，点下载
4. 把zip发给手抓饼

## 常见问题

**Q: 找不到GPU选项？**
A: 必须先验证手机号（Settings→Phone Verification）

**Q: 训练中断？**
A: Kaggle单次最长12小时，15分钟不会断；如果断了重新Save Version

**Q: 数据集下载失败？**
A: 检查Internet开关是否打开；Roboflow key失效就换一个公开扑克牌数据集

**Q: 不想用Kaggle？**
A: 备选：百度AI Studio（国内，免费V100 GPU）或AutoDL（1块钱）
